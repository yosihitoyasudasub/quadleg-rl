# 一本脚ホッパー 設計レポート（2D 検討の総括）

作成: 2026-09-07　対象: `tools/webapp/hopper-2d.html`（2D シミュレーター）と `docs/HANDOFF.md` §8 の検討結果

## 1. 目的と結論

**目的**: XM540-W270 × 2（ピッチ面の 5 節リンク脚）＋ ロール 1 個の 3 自由度で、跳びながらバランスし、前進もできる一本脚ロボットが成立するかを、実機を作る前に平面（2D）で判断する。

**結論**

| 項目 | 判定 | 根拠 |
| --- | --- | --- |
| その場ホップ 5 cm | 成立 | 425 ホップ連続、サーボ持続負荷 トルク 60 % / 速度 70 % |
| 外乱からの回復 | 成立 | ±0.3 m/s・0.1 rad の初期外乱を数ホップで回復 |
| 前進 0.2 m/s | 成立 | 0.16 m/s で安定追従（追従率 8 割）。0.3 m/s が速度上限 |
| 跳躍高の上限 | 12 cm | サーボ速度が無負荷回転数に達する点 |
| 前進速度の上限 | 約 0.3 m/s | 接地中の脚の掃引がサーボの速度予算を使い切る点（機構由来） |
| ロール面（左右、独立 2D） | 成立 | その場・外乱回復・横 0.2〜0.3 m/s。ロールサーボは **XH540-W150**（XM540 では速度不足） |
| MuJoCo 3D（連成） | 成立 | その場 5.0 cm、前進 0.15 m/s、横 0.2 m/s。2D の数値と一致（§7.6） |
| ヨー（横移動時） | 対策済み | 点接地 18.7°/hop → 足パッド（捩り摩擦 20 mm）で 3.8°/hop |

**設計の要点（結論として確定したもの）**
1. XM540 直結では跳べない。**直列バネ**を入れると成立する（着地エネルギーをバネで回収し、サーボは損失分だけ補う）。
2. クランク長 `l1` を伸ばして脚長方向の**伝達比**を上げると、サーボ負荷が速度からトルクへ移り、余裕が均される。
3. 接地中の股トルクは**電流制御**が必須。位置指令では制御周期の間にクランクが動く量に指令が埋もれる。
4. **股軸は重心の高さ**に置き、**下腿と足は 50 g 級**に軽くする。どちらもピッチ安定の条件。
5. 前進が出なかった原因は Raibert 式の中立点 `Ts/2` が **2 倍過補正**だったこと。接地写像を実測して係数を決めれば前進する。

## 3. 物理メカニズム

### 3.1 なぜ XM540 直結では跳べないか

ホップ 5 cm に必要な離陸速度は `v = √(2gh) ≈ 1 m/s`。XM540 は 30 rpm（3.1 rad/s）なので、足先を 1 m/s で動かすには有効腕が 320 mm 以上要り、その腕ではトルクが足りない。パワー（8.3 W/個）は足りているが、トルク─速度直線の「速度側」が 1〜2 桁不足する。

### 3.2 直列バネ（SLIP モデル）の役割

- 着地で胴体の運動エネルギーがバネに貯まり、跳ね返りで戻る。跳躍エネルギーの大半はこの回収分で、サーボは毎サイクルの損失（バネ減衰・接地減衰）を補うだけ。標準設定では蹴り出し量 7 mm で 5 cm を維持している。
- バネの固有振動 `√(k/m)/2π ≈ 3.9 Hz`、静的沈み `mg/k ≈ 16 mm`。接地時間は約 165 ms。
- バネはストローク（自然長 80 mm）で底付きする。ストローク不足だと着地エネルギーを失って跳べなくなる（初期に 40 mm で失敗した）。圧縮ピークは 55 mm。
- **軽量化するときはバネ定数を質量に比例して下げる**。バネ据え置きで軽くすると回収が減り、蹴り出しを使い切って速度飽和する。
- 直列バネは着地衝撃からギヤを守る。272:1 のギヤは逆駆動できないので、バネなしで着地すると衝撃がギヤに直接入る。

### 3.3 サーボの負荷がどこで決まるか

局面別の持続ピーク（5 ms 平均。瞬時値は指令段差で必ず 100 % に触れるので判断には使わない）:

| 局面 | トルク | 速度 | 何が決めているか |
| --- | --- | --- | --- |
| 接地・圧縮 | 26 % | 15 % | 着地力（約 65 N ≈ 4×mg）をリンク先端で支える |
| 蹴り出し | 59 % | 72 % | 荷重を支えながら脚を伸ばす。跳躍高にはあまり依存しない |
| 飛行 | 13 % | 31 % | 脚の引込みと足先配置。跳躍高が高いほど増える |
| 前進 0.2 m/s 時 | 69 % | 86 % | 接地中の脚の掃引が加わる |

- **軽量化はトルクにだけ効き、速度には効かない**（同じ高さを跳ぶなら脚を動かす速さは同じ）。
- **目標高を下げると飛行中の負荷が大きく下がる**（8 → 5 cm で速度 66 → 41 %）が、蹴り出しは小幅。
- 位置 PD の Kp が高い（120）と、離陸直後の目標段差に飛びついて反射慣性を無負荷回転数まで加速する。Kp 30 で飛行中の速度 95 → 67 %。

### 3.4 伝達比（可変機械利得）

対称姿勢の 5 節リンクは脚長方向に伝達比 `r = dL/dα`（脚長 mm / クランク rad）を持ち、`F = 2τ/r`、`v = r·ω`。`r` はパワーを増やさず、モータがトルク─速度直線のどこに載るかを変えるだけ。

- `r` は脚長に対して山なりで、両端（折り畳み・伸び切り）で 0 になる特異点。山の高さは `l1` にほぼ比例。
- `l1` を伸ばすと蹴り出しの負荷が速度からトルクへ移る（`l1 + l2 = 220` 固定）:

| l1 / l2 | 離陸時 r | 蹴り出し τ / ω | 飛行 τ / ω | 到達上限 | 外乱 0.3 m/s |
| --- | --- | --- | --- | --- | --- |
| 80 / 140 | 102 | 56 / 77 % | 15 / 43 % | 10 cm | 回復 |
| **90 / 130（採用）** | 124 | 59 / 72 % | 13 / 31 % | 12 cm | 回復 |
| 100 / 120 | 150 | 64 / 64 % | 11 / 29 % | 14 cm | 転倒 |
| 110 / 110 | 185 | 70 / 56 % | 9 / 23 % | 16 cm | 転倒 |

- `l1 ≥ 100` は `l2` が短くなって足先の横方向の余裕が減り、大きな速度外乱で転倒する。90 / 130 が頑健性を保てる上限。
- 四脚側（§3 の設計）とはトレードオフの向きが逆で、ホッパーと四脚で最適な `l1` は違う。

### 3.5 反射慣性

ギヤ比² × ロータ慣性 ≈ 0.02 kg·m²（推定）。足先換算で約 8 kg 相当と、胴体（1.5 kg）より重い「見かけの質量」が脚に付く。

- 着地衝撃を直列バネが受け持たないと、この慣性がギヤに衝撃を返す。
- 接地中に脚を横に押す指令を出しても、まずこの慣性の加減速に消費され、地面への力になりにくい。姿勢制御の効きが鈍い一因。
- 値は推定なので、実機のロータ慣性を測って更新する必要がある。

### 3.6 ピッチ安定の条件

- **股軸の高さ**: 接地力は股を通るので、股が重心より下（`hb > 0`）だと着地力 × 腕長 がピッチを倒す向きに働く。50 mm 下で転倒、30 mm 以下なら可。重心高さに置くのが正解。股を重心より上にすれば振り子として受動安定になる。
- **足の質量**: 飛行中に足を前に振ると反作用で胴体が機首下げに回る（角運動量保存）。胴体慣性 0.02 に対し足 0.15 kg × 0.24² = 0.009 では毎ホップ数度ずつ蓄積して転倒する。0.05 kg 以下にする。
- **接地中の姿勢トルク**: 位置指令で股トルクを出そうとすると、制御周期（5 ms）の間にクランクが動く量（0.1°）が指令オフセット（0.15°）と同程度で効かない。電流制御で `τ = Jᵀ F` を送ると効く。

### 3.7 前進速度の上限と、前進しなかった原因

**上限（機構由来）**: 接地中、足は固定され胴体が前進するので、脚は胴体に対して後方へ掃引する（角速度 `v/L`）。5 節リンクでは掃引を 2 クランクの同方向回転で作り、クランク 1 rad あたり足先は横に 0.11 m しか動かない。0.3 m/s の掃引にクランク 26 rpm（無負荷の 87 %）が要り、掃引と同じ向きの駆動トルク（機首下げ補正）を出す余地がなくなる。実測でも接地中の股モーメントは指令の約 1 % しか出ていなかった。速度上限 ≈ `J × ω₀ ≈ 0.17〜0.3 m/s`。

**前進しなかった原因（制御由来、解決済み）**: Raibert の足先配置 `xf = cn·vx·Ts/2 + Kv·(vx − vdes)` の中立点 `Ts/2` は、蹴り出しが接地後半ずっと続くこの機体では 2 倍過補正だった。定常ホップ中に入口速度と足先オフセットを強制して出口速度を測ると、接地写像は `v_out ≈ 3.1·v_in − 43·xf`（±10 mm で線形）。正しい中立点は `(a−1)/|b| = 0.048 s`、`Ts/2 = 0.083 s` の約 6 割。`cn = 1.0` のままでは、ループ方式を変えても毎ホップ前進を打ち消していた。

## 4. 制御

Raibert の 3 分割制御を基本にし、実測に基づいて 3 点を変更した。

| ループ | 方式 | 標準値 |
| --- | --- | --- |
| 跳躍高 | 最大圧縮を検出した後に脚長を `ΔL` 伸展（蹴り出し）。`ΔL += Kh·(h_des − h_apex)` | Kh 0.5、ΔLmax 50 mm |
| 前進速度 | 飛行中の足先配置 `xf = cn·vx·Ts_pred/2 + Kv·(vx − vdes)` | cn 0.5、Kv 0.03 s、ランプ 0.02 m/s/hop |
| 胴体姿勢 | 接地中の股トルク `M = Kθ·θ + Kθd·ω` を電流指令で | Kθ 40 N·m/rad、Kθd 1 |

**変更点**
1. **接地時間の予測**: 前回値でなく、バネ質量系の着地時間 `T = (2/ω)(π − atan(v0·ω/g))` を飛行中に予測し、実測比で補正（予測 164 ms / 実測 165 ms）。
2. **中立点係数 `cn`**: 接地写像から `(a−1)/|b| ÷ (Ts/2)` で決める。標準設定で 0.4〜0.6。0.4 は 5 cm 専用で追従 95 %、0.5 は 5〜10 cm と 50 Hz でも転倒しない汎用値（追従 75 %）。
3. **速度ゲイン `Kv`**: 写像の理論値 `1/|b| ≈ 0.023 s` 付近（0.03）。0.01 では 0.3 m/s の誤差に 3 mm しか動かず外乱で転倒する。
4. **目標速度のランプ**: ステップ指令の過渡で転倒するので 0.02 m/s/hop で内部的に緩める。

**接地中の指令の作り方（電流制御）**: 半径方向は脚長インピーダンス `Fr = Kr·er − Dr·vr`（蹴り出し中は減衰なしで飽和まで押す）、接線方向は `Ft = M/L`。`τ = Jᵀ F` を制御周期ごとに送る。飛行中は位置 PD。

**制御周期**: 500 / 200 Hz は安定、100 Hz は前進で振動、50 Hz はその場ホップのみ。前進には 200 Hz 以上。Dynamixel 3 個なら 4.5 Mbps で可能。

**サーボ逆駆動の禁止**: 蓄勢や過剰な蹴り出しでバネの解放がサーボを押し戻すと ω が無負荷回転数の 100 % を超える。272:1 のギヤは逆駆動できないので実機ではギヤが壊れる。シミュレーターは自由に逆駆動できるモデルなので、**ω > 105 % は設計失格**として扱う（結果パネルに表示）。

## 5. シミュレーターのモデルと限界

| 要素 | モデル |
| --- | --- |
| 胴体 | 剛体（質量・慣性）。ピッチ面のみ |
| 脚 | 質量なし 5 節リンク。解析 IK / FK、数値ヤコビアン |
| サーボ | 反射慣性 ＋ トルク─速度直線 `τ = stall·(1 − |ω|/ω₀)` で飽和。飛行中は位置 PD、接地中は電流指令 |
| 直列バネ | 足先方向のみ、自然長で底付き。横方向は剛（擬似拘束） |
| 足 | 質点。接地はバネダンパ ＋ クーロン摩擦（アンカー式） |
| 積分 | 固定 0.25 ms（4 kHz）半陰的オイラー。制御は選択周期で指令更新 |
| センサ | 速度・接地・姿勢は真値（推定誤差なし） |

**限界**: ロール軸なし、リンク質量なし、ギヤの摩擦・バックラッシュなし、反射慣性は推定値、接触は簡易。学習用ではなく「成立するかの判断」用。検証は `tools/hopper_harness.js`（Node で DOM を介さず実行）で行い、`tools/hopper_sweeps.js` に回帰と掃引がある。

**実装で踏んだ落とし穴**（再発防止）
- IK の ±180° 折返し: 目標角は現在角基準で unwrap する。
- バネのストローク不足: 底付きで着地エネルギーを失う。
- 位置オフセットで股トルクを表現できない: 電流制御にする。
- 瞬時ピークで負荷を判断しない: 5 ms 平均の持続ピークを見る。
- 閉ループ中は接地写像の `a` と `b` を同時同定できない（`xf` が `v_in` の関数で共線）。強制実験で測る。

## 7. 設計指針（まとめ）

1. 直列バネ 900 N/m・ストローク 80 mm 以上（1.5 kg 時）。質量を変えたら静的沈み 16 mm が保たれるようバネを比例させる。
2. クランク `l1 90 / l2 130`。伸ばすほど負荷は均されるが、`l1 ≥ 100` は外乱耐性を落とす。
3. 股軸は重心の高さ。下腿・足は 50 g 以下。
4. 接地中は電流制御。制御周期 200 Hz 以上。ω > 105 % を出さない。
5. 前進速度ループの係数は接地写像を測ってから決める（`cn = (a−1)/|b| ÷ (Ts/2)`、`Kv ≈ 1/|b|`）。構成を変えたら測り直す。
6. 実用範囲: 跳躍 5〜10 cm、前進 0.2 m/s まで。0.3 m/s 超と大きな跳躍を両立させるには機構変更（案 B か蓄勢方式 C）。

## 7.5 ロール面（段階 1、2026-09-08 追加）

`tools/webapp/hopper-roll-2d.html`。ピッチ面と独立に正面図で扱う（Raibert の 3D ホッパーと同じ分離）。股のロール軸は前後方向で重心高さ、脚面はロール軸を通す（横オフセット 20 mm で転倒）。

| 条件 | 結果 |
| --- | --- |
| その場ホップ | 5.0 cm、ロールサーボはほぼ無負荷。脚長サーボはピッチ面と同じ 56 / 77 % |
| 外乱 横 0.3 m/s・ロール 6° | 回復 |
| 横 0.1 / 0.2 / 0.3 m/s（XH540-W150、cn 0.7 / Kv 0.02） | 0.10 / 0.23 / 0.32 m/s、ロール ≤ 9°、τ ≤ 53 % / ω ≤ 78 % |
| 同 XM540 | 0.2 m/s 以上でロールサーボ ω 98 % に飽和し、0.25 m/s 前後のドリフトとロール 10° に固定 |

**物理**: 飛行中に足を横へ振ると、胴体のロール慣性（幅 160 mm で 0.007 kg·m²）が足の慣性モーメント（0.05 kg × 0.24²）と同程度のため胴体が逆に回る（20° の足振りで 9°）。接地でそれを戻す回転と掃引が重なり、30 rpm のサーボでは無負荷回転数に達して姿勢トルクが出せない。減速比の小さい XH540-W150（7.1 N·m、70 rpm、同寸法・同質量、電流制御あり）で解消する。胴体を広げる・足を軽くする・仮想的に速いだけのサーボでは解消しなかった。

横方向の接地写像は `v_out ≈ 3.4·v_in − 42·y_f`。ブラウザ上でも 253 ホップ連続で 0.22 m/s・ロール −4°・ロールサーボ 50 / 58 % を確認済み。

**3D で初めて分かった設計事項**
- 直列バネは股→足の線上に置く（脚面の鉛直に置くと足の前後ずれ × 接地力の機首上げモーメントが出る）。
- 蹴り出しと掃引が重なると片方のクランクが速度飽和し、寄生のピッチモーメントが出る。姿勢優先のトルク配分と蹴り出しトルク上限（0.75×stall）で抑える。
- 速度ループの係数は 3D で狭くなる（`cn 0.35 / Kv 0.02`）。定常偏差は足先配置の積分補正で消す。
- 点接地はヨーを止められない。足は半径 25 mm 程度のゴムパッドにする。
