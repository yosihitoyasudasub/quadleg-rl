蓄勢方式

C は飛行中にウインチでバネを縮め、ラッチが保持する。接地中に解放して着地エネルギーと一緒に放出する。蓄勢の力ループは脚の内部（弦）で閉じるので、脚サーボには乗らない。飛行時間内に巻き切れるかが成立条件。

胴体は剛体、リンクは質量なし（下腿相当は足質量に含める）。サーボはギヤ比²×ロータ慣性の反射慣性を持ち、トルク─速度直線（τ = stall·(1−|ω|/ω₀)）で飽和。飛行中は位置 PD、接地中は「電流制御」なら脚長インピーダンス＋股トルク（τ = Jᵀ F）を制御周期ごとに送る。直列バネは足先方向のみ（自然長で底付き）、横方向は剛。接地はバネダンパ＋クーロン摩擦。物理は固定 0.25 ms。速度・接地・姿勢は真値（推定誤差なし）。成立可否の判断用で、学習用ではない。
蓄勢モード C は Bow Leg Hopper（Zeglin & Brown, CMU 1998）方式。飛行中に専用の巻取りモータがバネを δpre まで縮め、ラッチ（弦）が保持する。巻取りトルクは τ = ks·δ·rc、巻取り速度はそのモータのトルク─速度直線から決まる。力ループは足と脚先端の間で閉じるので胴体にも脚サーボにも反力は出ない。接地中は弦がたるみ、最大圧縮でラッチが外れて蓄勢ぶん＋着地ぶんが一緒に放出される。成立条件は「飛行時間内に巻き切れること」で、必要な平均パワーは ½·ks·δpre² / 飛行時間。
